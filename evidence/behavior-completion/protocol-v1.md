## Conservative complete-answer grammar

Gate metric is **terminated conservative-answer correctness**, not unrestricted semantic accuracy. It can undercount legitimate explanations; unparsed is reported separately from a parsed wrong answer. Strip exterior Unicode whitespace only; do not normalize characters. Whole string must be one digit0–9 for COPY/SUBTRACT or 大/小 for COMPARE, optionally prefixed by exactly one of: empty, 答案是, 答案：, 答案:, 结果是, 结果：, 结果:. COPY additionally allows 甲写下的数字是 or 甲写下的是. COMPARE additionally allows 它更; bare 大于/小于 are accepted as 大/小. Allow at most one final 。 or ASCII full stop on the main grammar (bare 大于/小于 exact only). No internal whitespace. No arbitrary text extraction or convenient last digit. Arithmetic equations, signed/decimal/multidigit values, repeated values, operands echoed from prompt, negations, alternatives and contradictions are unparsed. This is a frozen operational grammar, not a universal language parser.

Strict compliance is separately reported: complete/no control tokens and exterior-stripped text exactly equals the expected single digit or 大/小, without prefix or punctuation. Correctness includes strict answers; strict does not gate selection. Incomplete/control/unparsed/parsed-wrong counts and complete raw responses are required. No parser adjustment after seeing any model output.
