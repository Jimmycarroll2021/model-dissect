## Recommendation 1: one head at the attention output projection input

For a third GPT-NeoX model, add a native `register_forward_pre_hook` to `model.gpt_neox.layers[L].attention.dense`. Installed Transformers 5.1.0 source (`modeling_gpt_neox.py`, lines 181–184, 249–250) forms attention-weighted values, transposes to sequence-major head order, flattens the head dimensions, and calls `dense`. Thus its input is the useful pre-output-projection seam: clone `[B,S,H*d_head]`, reshape `[B,S,H,d_head]`, replace only the selected head at the frozen final real-token position, then reshape back. Keep the original packed output projection operation, so no new sum-of-heads floating-point ordering is introduced. This is a concrete compatibility inference from installed source, not an executed adapter.

Choose one layer/head using development only; bound the sweep to a preregistered small set or reserve the full sweep before execution. Retain the two directions, orthogonal control in the same head-dimensional space, exact edit-complement checks, no-op, hook-count, restoration, and parameter hashes. Verify captured head layout against an independently computed attention-weighted-V tensor, run native/candidate baseline parity first, and independently repeat every held-out arm. Qualify all baseline contrasts without changing the existing acceptance denominator. A result concerns this intervention/site/contrast, not head necessity or a complete circuit. If another architecture is selected, verify its output-projection seam and head packing afresh.

## Recommendation 2: preregister metric sensitivity without extra forwards

The current primary contrast chooses vocabulary indices from baseline logit differences and tests bidirectional normalized recovery. Keep that distributional interpretation explicit: it does not establish correct answers or factual understanding. Add raw unnormalized target-minus-control logit-difference effects and donor-directed KL improvement as secondary measurements computed from the already retained complete logits. Report per-pair results and a seeded paired bootstrap interval, resampling whole prompt pairs (both directions remain together), on a frozen statistic. Small-set intervals are descriptive, not population-wide certainty. Do not change the primary verdict when a secondary metric is favorable. Freeze KL direction and numerical implementation before seeing held-out data; flag probability underflow/nonfinite results rather than silently dropping cases. No model-run budget increase is needed for metrics on saved arrays.

Zhang and Nanda show that corruption and metric choices can change localization results; use matched natural prompt replacements and report metric sensitivity. [Paper v2, 2024-01-17](https://arxiv.org/html/2309.16042v2). Heimersheim and Nanda distinguish noising/denoising evidence, warn about redundancy and metric interpretation, and motivate restricting claims from a successful patch. [Paper v1, 2024-04-23](https://arxiv.org/html/2404.15255v1). These sources support the design, not numerical thresholds for this model.
