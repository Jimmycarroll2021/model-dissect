## Why this is a meaningful next test

CPU canonical scheduling violated native-prefill tolerance, so it is not an accepted repair. CUDA uses different arithmetic kernels and may meet the original native cache/full requirement without changing attention mathematics or reference layers. Testing native self-consistency first avoids spending on a candidate port when the backend's original model already fails. Different backend results are expected to be possible, not guaranteed to be better: [PyTorch numerical accuracy](https://docs.pytorch.org/docs/2.15/notes/numerical_accuracy.html) does not promise shape-invariant floating-point results. Determinism controls repeatability, not cache/full equality.
