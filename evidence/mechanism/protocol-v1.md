## Single hypothesis and deterministic development selection

H1: In this checkpoint and full-prefill mode, one development-selected block-0 residual-contribution coordinate selectively supports the correct-versus-foil next-token margin on copying prompts: zeroing that coordinate at the final input position reduces that margin more than an activation-norm-matched coordinate, while unrelated completion ability is largely retained.

For each coordinate j compute Pearson correlation of its final-position contribution with baseline correct-minus-foil logit margin across the8 development copying rows. Exclude zero-variance coordinates. Choose maximum positive correlation (tie lower index), requiring r>=0.5. This is a prior-informed correlation-selected hypothesis, not neuron semantics. Choose a different coordinate with copying-development RMS contribution within20% of target RMS, minimizing absolute margin correlation (tie lower index). Require target RMS>0 and control RMS>0. Freeze target/control indices, all selection statistics and control scale `s=RMS(target)/RMS(control)`; matching is population-norm matching on development, not per-example held-out adaptation. Scale control's removed contribution by s; values may exceed1. A control deficit is inconclusive, no fallback search.

## Arms and measurements

Order fixed: baseline(no hooks), noop(identity hook), target(zero selected coordinate at last real position), matched(control contribution changed by subtracting s times its original value there), restored(no hook, fresh forward). No weight writes. Record actual removed activation L2 per row and arm; report held-out magnitude mismatch honestly. On the16 copying held-out rows only, compute abs(mean(control removed L2)/mean(target removed L2)-1); zero target mean makes the result inconclusive. If this ratio exceeds0.25, specificity is inconclusive even if effects are large.

Primary per-row metric: margin=logit(expected)-logit(foil); effect E=baseline margin minus arm margin. Report all margins, E_target, E_control, paired specificity D=E_target-E_control, target win counts, and descriptive means/medians. Capability metrics: expected-next-token NLL and top1 accuracy on unrelated rows, baseline and all arms; additionally full-vocabulary top1 changes and mean absolute logit differences on every row. Do not use top1 stability alone as unchanged capability. Report copying baseline accuracy; task prerequisite is >=6/8 dev and>=12/16 heldout correct expected-vs-foil choices (margin>0). Fail prerequisite => inconclusive, not a new task search.

(1) If any M2/tool/control/restoration/finite-data/task prerequisite fails, the copying held-out norm match fails, unrelated mean target NLL increase exceeds0.10nats, unrelated accuracy drop exceeds1/16, or independent-repeat verdict disagrees: **inconclusive**.
