Static / no input sequence

1. What connects the coordinates?

The atlas contains 144 head-norm entries and saved QK/OV matrices for 12 selected sites. Layer 8, head 8 is one of those sites; it was selected using development data. The pictures below are that site's actual saved matrices, each originally 768 × 768.

Both panels use a 24 × 24 display: each cell is the float64 arithmetic mean of one non-overlapping 32 × 32 block of the saved float32 matrix. This can cancel opposing values. Blue = positive; orange = negative; white ≈ zero. Each panel uses its own maximum absolute block mean, so colors are not comparable between panels. Hover a cell for its block value; inspect exact numeric means below. Full-resolution source arrays are retained.

These are coordinate maps, with no assigned semantic names. They omit layer normalization, biases, learned positions, softmax and context. A weight pattern alone cannot establish what the head does or whether it causes an output.

Sources: atlas/additive-v2-producer/raw/layer8.head8.QK.npy and .OV.npy; file and array hashes below. GPT-2 Conv1D weights use input × output orientation; the head slice spans packed head coordinates 512–575.

The control changes the same 64-dimensional slice by a norm-matched direction orthogonal to donor − recipient. It tests direction-specific transfer against perturbation size.
