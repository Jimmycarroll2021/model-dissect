## User Scenarios & Testing

### User Story 1 — Inspect a genuinely different model (P1)
Jimmy can identify the acquired model, inspect every stored tensor and follow each role into the computation.
**Independent test**: Exhaustive inventory matches the frozen checkpoint; every tensor has dimensions, role, equation and provenance. Stored versus tied logical parameters are distinguished.
**Acceptance**: Given the pinned source/config/tokenizer/weights, inspection produces complete accounting and an architecture-aware explanation; a changed file causes identity rejection before execution.

### User Story 2 — Run and modify an independently reconstructed computation (P1)
Jimmy has editable computation whose measured outputs agree with a separately operated native reference in a declared mode, including genuine cached continuation.
**Independent test**: The complete frozen matrix passes all numerical and internal-boundary gates twice, once by a separate verifier, with no-op/restoration checks.
**Acceptance**: Native reference and reconstructed candidate are distinct; a reference-forward wrapper fails independence even if logits agree. Failed comparisons remain failures.

### User Story 3 — Follow an input and investigate an internal effect (P1)
Jimmy can inspect a saved real-input trace and a controlled internal experiment with an honest outcome.
**Independent test**: Frozen development selection, distinct held-out evaluation, baseline/no-op/target/matched-control/restored arms and independent repetition establish the precise supported, refuted or inconclusive result.
**Acceptance**: Failed behavioral qualification produces STOP_NO_QUALIFIED_BEHAVIOR and blocks unsupported mechanism claims; it does not count as a completed intervention experiment.

### Edge Cases
Unknown tensors, omitted tied weights, config/weight disagreement, incompatible tokenizer, nonfinite output, masked positions, left/right padding, positional limits, local-attention cache semantics, failed restoration, exhausted budgets and accidental held-out exposure must produce explicit outcomes without silently dropping cases or rewriting old receipts.
