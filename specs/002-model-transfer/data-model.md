# Transfer records

ArtifactManifest: upstream revision/license, file paths/bytes/SHA256, immutable parent, source exposure, environment lock.
TensorMap: exact key/shape/dtype/storage alias, logical role, dimensions/equation, config/source provenance, unresolved status; set equality with inventory required.
Protocol: candidate/reference/fixture identities, masks/positions/cache semantics, boundaries, comparator, counts, resource ceilings and scientific decision rules.
RunReservation: unique ID, role, manifest/protocol/input hashes, expected calls/positions, elapsed/RSS/disk limits, output path; reserved → running → passed/failed/interrupted, never silently reused.
Hypothesis: development provenance, target/control site, intervention, prediction, qualification and effect/specificity/denominator rules, freeze identity before holdout.
Result: per-case/per-arm arrays and metrics, comparisons, failures, charged resources, exact execution identity.
DeliveryManifest: all current artifacts and separate verifier receipt; changing bytes invalidates affected acceptance only. TASK_STATE remains sole lifecycle controller.
