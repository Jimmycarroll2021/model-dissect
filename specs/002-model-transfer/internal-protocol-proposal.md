## Fixed question and architecture scope
Does replacing the last-position output of one intermediate transformer block with the corresponding output from a matched alternate prompt move the next-token distribution toward the donor more than an equal-norm orthogonal perturbation? Candidate sites are block0..4; block5 is excluded in advance to avoid the trivial last-block-to-unembedding replacement. Each intervention changes one128-dimensional residual vector at physical position31 and no other position. This is a coarse sufficiency/directional-effect test conditional on prompt pairs, not recovered semantics.

NativeReference.boundary_hook(index,hidden) and candidate boundary_hook already expose block outputs. Use the native source-assisted implementation for science; the independent candidate supplies the separately gated numerical reconstruction and actual-input parity. Do not rename block effects as individual head effects. No head instrumentation or new generalized framework is required.

## Baselines, contrast and eligibility
For each pair save native full50304-dimensional final-position baseline logits zA,zB and all6 last-position block vectors. Compute d=zA-zB, contrast IDs u=argmax(d),v=argmin(d), tie lowest numeric ID. Compute D(z)=z[u]-z[v] and g=D(zA)-D(zB). This algorithm is fixed before heldout; it does not select cases after seeing intervention outcomes. All50304 output IDs participate, including IDs without tokenizer decoding (display numeric ID). No chat/QA accuracy requirement.

Contrast eligibility requires u!=v and finite g>=0.01. Site/direction eligibility additionally requires finite donor difference norm>=1e-8. Ineligible rows remain in every denominator and all interventions are still executed. No eligibility-driven new prompt search. Zero-norm donor replacement becomes an explicitly recorded zero edit; its control also zero. Nonfinite values are execution failures, never filtered observations.

For A→B at layerL, delta=hA[L]-hB[L]; target replaces recipient hB with hA. Reverse uses -delta at recipientA. Matched control uses an orthogonal vector with exactly the same L2norm as delta: q=roll(delta,1)-delta*dot(roll(delta,1),delta)/dot(delta,delta); if norm(q)<1e-8, use unit coordinate e_k with k=argmin(abs(delta)), subtract its projection onto delta, then normalize. For reverse use -q. All norm/dot calculations use a frozen specified implementation and dtype; FP64 may be used solely for diagnostic metric/control construction, never native/candidate forward mathematics. Control vector finally cast FP32; require relative norm mismatch<=1e-5 and absolute normalized dot<=1e-5; invalid construction is FAIL_CONTROL, not an opportunity to change matching. Save vectors and measured norm/cosine. Control at same layer avoids selecting a deliberately weak different layer.

## Fixed development selection and heldout rule
Run both target and orthogonal-control directions at all5sites on all8 development pairs. For each direction compute donor recovery r: forward=(D(zpatchedB)-D(zB))/g; reverse=(D(zA)-D(zpatchedA))/g. Retain unbounded raw values. Primary per-pair score=min(rforward,rreverse), set0 for ineligible pairs/sites. Paired advantage=target_primary-control_primary. Select layer maximizing median development paired advantage, tie lower layer. Always freeze that one selection, even if all scores are0 or negative; no development success screen/reselection. Thus the experiment still executes a meaningful bounded intervention/control study when donor alignment is weak.

Heldout executes all16pairs at selected layer. SUPPORTED_BOUNDED_BLOCK_EFFECT requires >=12/16eligible, >=12/16 strictly positive target bidirectional effects, median target_primary>=0.10 and median paired advantage>=0.05. REFUTED_DIRECTIONAL_PREDICTION requires >=12/16eligible and median paired advantage<=0. Otherwise INCONCLUSIVE. Fixed16 denominator; no eligibility removal. These are descriptive preregistered effect rules, not statistical generalization or a p-value claim. Report each pair, eligibility, absolute distribution changes, control damage and all threshold results.

Fallback is predeclared measurement, not a new success threshold: for every ineligible pair still report target/control RMS full-logit change, centered-logit RMS, softmax total variation, cosine toward donor when defined, edit norm and top1 change. No normalized donor-recovery claim when g is too small. All-ineligible data means INCONCLUSIVE_NO_ELIGIBLE_CONTRAST and no donor-mediated causal claim. Completed arms demonstrate controlled perturbation sensitivity/restoration only; controller must not call absent qualifying mechanism evidence a positive discovery. No added model calls or alternate protocol follows automatically.
